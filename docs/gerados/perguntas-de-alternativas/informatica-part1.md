### Pergunta
No Windows 10, ao pressionar simultaneamente as teclas Win + D, o que ocorre na área de trabalho?

### Alternativas
- A) Abre o menu Iniciar.
- B) Minimiza ou restaura todas as janelas abertas, exibindo a área de trabalho.
- C) Abre o Gerenciador de Tarefas.
- D) Bloqueia a tela do computador.

### Resposta Correta
B

### Explicação
O atalho Win + D alterna entre mostrar a área de trabalho (minimizando todas as janelas) e restaurar as janelas ao estado anterior. Win + L bloqueia a tela; Ctrl + Shift + Esc (ou Ctrl + Alt + Del → Gerenciador de Tarefas) abre o Gerenciador de Tarefas; a tecla Win sozinha abre o menu Iniciar.

### Pergunta
No Microsoft Word, ao utilizar o atalho de teclado Ctrl + Z, qual ação é executada?

### Alternativas
- A) Refaz a última ação desfeita.
- B) Salva o documento atual.
- C) Desfaz a última ação executada.
- D) Fecha o documento sem salvar.

### Resposta Correta
C

### Explicação
Ctrl + Z é o atalho universal de "desfazer" (undo) no Word e na maioria dos aplicativos Windows. O atalho para refazer é Ctrl + Y; para salvar é Ctrl + S; não existe atalho padrão de Ctrl + Z para fechar sem salvar.

### Pergunta
Em uma planilha do Microsoft Excel, a célula A1 contém o valor 200 e a célula B1 contém o valor 50. Qual fórmula calcula corretamente o percentual que B1 representa em relação a A1?

### Alternativas
- A) =A1/B1*100
- B) =B1/A1*100
- C) =B1-A1
- D) =(A1+B1)/100

### Resposta Correta
B

### Explicação
Para calcular o percentual de B1 em relação a A1, divide-se o valor parcial (B1 = 50) pelo valor total (A1 = 200) e multiplica-se por 100: =B1/A1*100 resulta em 25%. A alternativa A inverte a divisão; C calcula diferença; D soma e divide, o que não representa percentual relativo.

### Pergunta
No Microsoft Excel, qual função retorna o maior valor numérico de um intervalo de células?

### Alternativas
- A) =SOMA(intervalo)
- B) =MÉDIA(intervalo)
- C) =MÁXIMO(intervalo)
- D) =CONT.NÚM(intervalo)

### Resposta Correta
C

### Explicação
A função =MÁXIMO(intervalo) retorna o maior valor numérico do intervalo especificado. =SOMA soma todos os valores; =MÉDIA calcula a média aritmética; =CONT.NÚM conta quantas células contêm valores numéricos. Para o menor valor usa-se =MÍNIMO.

- A) Inserir → Símbolo.

### Pergunta
Qual protocolo de e-mail permite que as mensagens sejam mantidas no servidor e sincronizadas em múltiplos dispositivos (computador, smartphone, tablet), ao contrário do protocolo que baixa e remove as mensagens do servidor?

### Alternativas
- A) POP3 — mantém mensagens no servidor para múltiplos dispositivos.
- B) SMTP — utilizado para enviar e sincronizar mensagens entre dispositivos.
- C) IMAP — mantém mensagens no servidor e sincroniza entre múltiplos dispositivos.
- D) FTP — protocolo usado para acessar e-mails de qualquer dispositivo.

### Resposta Correta
C

### Explicação
IMAP (Internet Message Access Protocol) mantém as mensagens armazenadas no servidor e sincroniza o estado (lida, excluída, pasta) entre todos os dispositivos conectados. POP3 (Post Office Protocol 3) baixa as mensagens para o dispositivo e, por padrão, remove do servidor. SMTP é o protocolo de envio de e-mails. FTP é um protocolo de transferência de arquivos, sem relação com e-mail.

### Pergunta
Em relação ao armazenamento em nuvem, assinale a afirmativa CORRETA:

### Alternativas
- A) Os arquivos armazenados na nuvem ficam gravados apenas no computador local, sendo espelhados para o servidor quando há conexão.
- B) O acesso a arquivos na nuvem exige sempre a instalação de um software dedicado, não sendo possível via navegador.
- C) Serviços de nuvem como OneDrive, Google Drive e Dropbox permitem acesso, compartilhamento e colaboração em arquivos a partir de qualquer dispositivo com internet.
- D) A nuvem elimina completamente a necessidade de senhas, pois o acesso é feito por reconhecimento do dispositivo.

### Resposta Correta
C

### Explicação
O armazenamento em nuvem permite acesso, compartilhamento e colaboração em arquivos de qualquer dispositivo com conexão à internet, sendo esse o principal benefício do modelo. As demais alternativas estão incorretas: os arquivos são armazenados em servidores remotos (não só localmente); a maioria dos serviços permite acesso via navegador sem instalação de software; e autenticação com senha (ou múltiplos fatores) continua sendo necessária.

### Pergunta
Ao acessar um site cujo endereço começa com "https://", em vez de "http://", o usuário recebe a garantia de que:

### Alternativas
- A) O site é isento de vírus e o download de arquivos é seguro.
- B) A comunicação entre o navegador e o servidor é criptografada, protegendo dados transmitidos.
- C) O site foi verificado e aprovado pelo Governo Federal Brasileiro.
- D) Nenhuma informação pessoal será coletada pelo site.

### Resposta Correta
B

### Explicação
O "S" em HTTPS significa que a comunicação usa o protocolo TLS/SSL para criptografar os dados trafegados entre o navegador e o servidor, dificultando a interceptação por terceiros. Isso não garante ausência de vírus, aprovação governamental ou ausência de coleta de dados — apenas que a comunicação é cifrada e que o certificado do servidor foi validado por uma autoridade certificadora.

### Pergunta
O ataque cibernético em que o criminoso envia mensagens fraudulentas (geralmente por e-mail) se passando por instituições legítimas para enganar o usuário e obter senhas, números de cartão ou outros dados pessoais é denominado:

### Alternativas
- A) Ransomware
- B) Phishing
- C) Brute force
- D) SQL Injection

### Resposta Correta
B

### Explicação
Phishing é a técnica de engenharia social em que o atacante se disfarça de fonte confiável (banco, governo, empresa) para induzir a vítima a fornecer credenciais ou dados sensíveis. Ransomware é um malware que criptografa arquivos e exige resgate; brute force testa combinações de senhas automaticamente; SQL Injection explora falhas em bancos de dados de aplicações web.

### Pergunta
Com relação à política de backup, assinale a alternativa que representa a boa prática recomendada para garantir a recuperação de dados em caso de falha ou desastre:

### Alternativas
- A) Armazenar o único backup no mesmo disco rígido do computador principal, para acesso mais rápido.
- B) Realizar backup apenas dos arquivos criados na última semana, pois arquivos antigos raramente são necessários.
- C) Manter cópias de backup em locais físicos ou lógicos distintos da origem (regra 3-2-1: 3 cópias, 2 mídias diferentes, 1 offsite).
- D) Dispensar testes de restauração, pois o simples fato de haver cópia garante a recuperação dos dados.

### Resposta Correta
C

### Explicação
A regra 3-2-1 é a prática mais recomendada: manter 3 cópias dos dados, em pelo menos 2 tipos de mídia diferentes, com pelo menos 1 cópia armazenada em local externo (offsite) ou na nuvem. Armazenar o backup no mesmo disco da origem não protege contra falha do disco ou incêndio; fazer backup apenas de arquivos recentes gera perda de dados históricos; e testes periódicos de restauração são essenciais — um backup que não pode ser restaurado não tem valor.
